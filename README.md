# ShopEasy - Flipkart-style E-commerce Website

A complete Flipkart-style e-commerce website with 12 products, mandatory authentication, and full responsiveness.

## Features

1. **Flipkart-style Design** - Modern UI with blue theme similar to Flipkart
2. **8 Products Only** - Exactly 8 products for sale across different categories
3. **Mandatory Authentication** - Users must login/signup to purchase
4. **Full Responsiveness** - Works perfectly on mobile, tablet, and desktop
5. **Complete Shopping Flow** - Browse → Add to Cart → Checkout → Order Confirmation
6. **User Authentication** - Login/Signup system with form validation
7. **Shopping Cart** - Add/remove items, update quantities
8. **Checkout Process** - Address selection, payment methods, order placement
9. **Product Details** - Detailed product pages with specifications
10. **Deals & Categories** - Organized shopping experience
